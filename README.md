# Clado Official Documentation

Official documentation site for **Clado (`cladogram`)**, built with [VitePress](https://vitepress.dev/) and deployed automatically to GitHub Pages.

- **Online Docs (中文默认 / English)**: https://godshelvis.github.io/clado-docs/
- **npm Package**: https://www.npmjs.com/package/cladogram

## Local Development

```bash
npm install
npm run docs:dev
```

## Production Build

```bash
npm run docs:build
npm run docs:preview
```
