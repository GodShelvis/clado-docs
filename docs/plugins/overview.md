# 内置插件总览

Clado 默认随产品提供 **4 个核心内置插件**，统一归属于受内核强保护的 `clado.*` 命名空间。它们分别挂载在画布的四个悬浮角落，共同组成开箱即用的桌面与移动端工作台。

![Clado 本体内核与四大内置插件插槽分布](/images/plugin-slots-map.svg)

## 内置插件的共同特性

### 1. 受保护的 `clado.*` 命名空间

内核在启动加载阶段会对插件 ID 执行强校验：

- 只有随 Clado 本体分发的官方内置插件才允许声明 `clado.*` 前缀；
- 任何外部本地目录、Git 或插件市场来源的插件若试图使用 `clado.*` ID，都会在解析阶段被拒绝加载，防止核心入口被仿冒或劫持。

### 2. 统一的透明毛玻璃视觉体系

四个内置插件全部采用 Clado 本体提供的无侵入毛玻璃组件原语：

- **静默克制**：收起状态下只以紧凑悬浮胶囊或图标停留在画布四角，不遮挡核心内容区；
- **双主题自适应**：自动跟随浅色 / 深色主题切换背景透明度、边框微光与文字对比度；
- **桌面 / 移动端自适应**：桌面端保持四角悬浮，小屏移动端自动收敛为顶部紧凑栏 + 底部抽屉（Bottom Sheet）+ 44px 触控热区。

### 3. 可在「插件管理」中按需开关与配置

打开左上角 [`clado.brand`](/plugins/brand) → **插件管理** 弹窗，你可以查看全部内置与外部插件的运行状态：

- 支持独立启用或停用非必需插件（变更后点击「应用并刷新」生效）；
- 支持直接点击插件卡片上的 **设置** 按钮可视化编辑插件配置（如为 `clado.agent` 配置 LLM 协议、API Key 与默认模型）。
