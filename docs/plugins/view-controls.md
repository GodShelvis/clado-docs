# `clado.view-controls` · 视图切换与诊断栏

`clado.view-controls` 是画布右上角的**视图控制器与文档健康指示器**，负责在三大同源视图间无延迟切换，并在需要时动态浮现诊断问题计数与「退出聚焦」快捷按钮。

## 位置与外观

- **桌面端位置**：固定悬浮于画布右上角（`top-right` 插槽），与左上角 `clado.brand` 形成极简对称的顶部操作带。
- **主控分段条**：采用胶囊形毛玻璃分段控件（Segmented Control），内部配有一块平滑滑动的高亮滑块（`.clado-view-thumb`），在 **卡片** / **脑图** / **文档** 三个视图间切换时呈现细腻的横向位移动画。
- **按需浮现的状态胶囊**：主分段条下方预留状态栏（`.clado-view-status`），**平时完全隐藏不占空间**，仅当文档存在诊断问题或当前处于聚焦模式时才悄然浮现对应按钮。
- **移动端适配**：窄屏下保持在顶部右侧，胶囊内边距微缩并与左上角品牌徽标自动保持安全间距，点击切换无误触。

## 核心功能详解

### 1. 三视图瞬时切换

同一份 `.md` 源文件随时可以在三种呈现形态之间无损切换，且自动记忆当前文档路径与选中节点：

| 视图按钮 | 渲染形态 | 最佳适用场景 |
| --- | --- | --- |
| **卡片** | 自动分层的架构卡片 + 贝塞尔有向连线 + 语义 Tag 锚点 | 技术架构设计、接口调用链梳理、代码改造方案评审 |
| **脑图** | 左右发散的层级思维导图 + 折叠分支 | 测试用例拆解、需求脑暴、模块边界巡检 |
| **文档** | 干净清爽的线性长文阅读流 | 从头到尾顺读方案正文、导出与离线归档 |

关于三种视图的详细交互说明，可参阅 [三大视图与画布交互](/syntax/views-and-interactions)。

### 2. 实时诊断问题计数器（`N 项问题`）

Clado 本体会在每次文件解析后执行全量诊断（包括悬空链接、重复 `tagId`、模板结构缺失等）。

- **零问题时静默隐藏**：文档完全健康时界面不出现任何冗余绿标或噪音提示。
- **存在警告 / 错误时自动浮现**：右上角分段条下方出现 `N 项问题` 胶囊；若包含阻塞级 `error`，胶囊自动呈现柔和警示高亮，鼠标悬停可看到精确的 `X 个错误 · Y 个警告` 摘要。
- **一键打开诊断面板**：点击计数胶囊即可展开完整诊断列表，逐条查看违规规则代码、所在卡片及修复建议。

### 3. 退出聚焦快捷按钮（`退出聚焦`）

当你在卡片视图中点击某张卡片或语义 Tag 锚点进入**调用链聚焦模式**时，无关节点会被柔和淡化以突出上下游路径。

- 此时 `退出聚焦` 胶囊会自动浮现在视图切换栏下方；
- 点击该按钮（或在画布空白处点击 / 按 `Esc`）即可立刻恢复全图视野。

## 交互细节与无障碍设计

- 分段按钮组严格遵循 WAI-ARIA 规范（`role="group"` + `aria-pressed`），支持键盘 `Tab` 导航与空格/回车切换；
- 诊断胶囊包含完整的 `aria-label`（例如 `2 个错误 · 1 个警告，查看诊断`），方便屏幕阅读器识别。
