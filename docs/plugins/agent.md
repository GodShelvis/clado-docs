# `clado.agent` · 灵感垂直 Agent

`clado.agent` 是画布右下角的**系统级原生 AI 研发协作工作台（界面名：灵感）**。它不仅是一个对话侧边栏，而是直接理解当前画布节点、选区与语义 Tag 的垂直 Agent，覆盖从架构设计、测试用例拆解、Diff 验收到 ACP 派发开发的完整闭环。

## 位置与外观

- **桌面端位置**：固定悬浮于画布右下角（`bottom-right` 插槽）。
- **收起状态**：显示为精致的毛玻璃胶囊按钮，带灯泡火花图标与 **灵感** 文字，静默不干扰阅图。
- **展开状态**：向上展开悬浮毛玻璃工作台面板（`#clado-agent-panel`），顶部是标题与快捷操作栏，中部为工作模式切换、人设选择与流式对话记录，底部是自适应输入框与发送/停止按钮。
- **AI 生成态专属视觉反馈**：当且仅当 Agent 正在执行推理、调用工具或读写画布时，面板底边中央会泛起一条**宽度 ≥ 80%、左右柔和羽化渐变消失的柔光呼吸带**，并随流式输出轻缓脉动；任务结束或空闲状态下光带完全隐去，绝不在普通点击时制造视觉噪音。
- **移动端适配**：窄屏设备上自动展开为占屏 `86dvh` 的 Bottom Sheet 底部抽屉，自动适配软键盘与底部 Home Indicator 安全区。

## 核心功能详解

### 1. 顶栏控制项

| 控件 | 说明 |
| --- | --- |
| **Provider 标识** | 标题下方以小字显示当前驱动协议与模型名称（例如 `Anthropic · claude-sonnet` 或 `OpenAI · gpt-4o`）。 |
| **`跟随`** | 开启后，当 AI 读取、修改或定位某张卡片时，画布镜头会自动平滑平移并聚焦到 AI 正在操作的节点，获得强烈的现场协作感。 |
| **`历史`** | 展开历史会话列表，会话以纯文本形式持久化保存在工作区 `.clado/sessions/` 中，可随时切换恢复上下文。 |
| **`新对话`** | 清空当前上下文并开启一条全新的垂直协作会话。 |

### 2. 四大研发工作流模式

面板顶部内置四个一键切换的工作模式芯片（Workflow Chips），自动装配对应的系统提示词、工具策略与输出规范：

| 工作模式 | 核心目标 | 典型产出 |
| --- | --- | --- |
| **架构设计** | 基于需求或现有代码仓库梳理调用链、模块边界与改造方案 | 带语义 Tag 与精准连线的卡片视图方案文档 |
| **测试用例** | 根据架构文档与边界条件自动推导完整测试矩阵 | 结构清晰、可直接切脑图审阅的测试用例树 |
| **Diff 验收** | 结合 Git Diff 或代码变更与设计文档逐项核对实现偏差 | 标注绿色新增 / 琥珀色修改 / 红色风险的验收卡片 |
| **派发开发** | 将已经过你确认的设计方案与选定节点，一键封装任务单派发给本地 ACP 代码执行器 | 调用执行器修改真实仓库代码并回传进度 |

### 3. 三种专业人设（Persona）

可通过 **人设** 下拉框独立切换对话视角：

- **研发架构师**：侧重系统边界、数据一致性、性能与可演进性；
- **QA 测试专家**：侧重边界条件、异常流、幂等性、并发竞争与回归用例覆盖；
- **验收审计官**：侧重严格核对设计承诺与实际代码实现之间的落差与潜在风险。

当切换到 **派发开发** 模式时，下方会自动出现 **执行器** 下拉框，供你选择已注册的本地 ACP 编码执行器（如 ZCode 或自定义 ACP 插件）。

### 4. 真 Token 流式输出与人机决策拍板（`ask_user`）

- **双协议真流式渲染**：原生支持 OpenAI 协议与 Anthropic 协议（含 Prompt Caching），实时逐字渲染正文与可折叠的「思考过程（Thinking）」区块，工具调用折叠展示执行参数与结果摘要。
- **结构化拍板卡片**：当方案出现多条合理路线时，Agent 会主动调用 `ask_user` 暂停执行，并在对话流中渲染一张带推荐标记的决策卡片，让你直接点选方案或补充自定义意见后继续推进。

## 如何配置 `clado.agent`

你可以直接通过 UI 完成配置，无需手动改配置文件：

1. 点击画布左上角 [`clado.brand`](/plugins/brand) → **插件管理**；
2. 找到 **灵感**（`clado.agent`）并点击右侧 **设置**；
3. 选择协议类型（OpenAI / Anthropic），填入 `baseUrl`、`apiKey` 与 `model` 并保存即可生效。
