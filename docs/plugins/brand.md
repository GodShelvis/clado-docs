# `clado.brand` · 品牌与全局设置

`clado.brand` 是画布左上角的**系统主菜单与全局控制中心**，承载 Clado 品牌标识、主题外观切换、画布一键截图以及可视化插件管理与安装入口。

## 位置与外观

- **桌面端位置**：固定悬浮于画布左上角（`top-left` 插槽），远离画布核心视野。
- **收起状态**：呈现为半透明毛玻璃圆角胶囊，左侧绘制 Clado 全新矢量徽标（蓝点弧线与柔和微光），右侧配克制的 `clado` 小写字标。
- **展开状态**：点击胶囊向下展开浮动毛玻璃设置面板（`#clado-brand-settings`），采用单色克制排版与极细分隔线；点击菜单外任意空白处或按 `Esc` 键即可无感收起，并将焦点自然归还给触发按钮。
- **移动端适配**：在窄屏设备上保持顶部左上角紧凑胶囊，点击后下拉菜单自动对齐安全区边距，菜单项均保证 ≥ 44px 触控高度，单手即可点选。

## 核心功能详解

### 1. 日间 / 夜间双主题切换

面板顶部提供两种单色调外观模式，当前激活项右侧以勾选图标标明：

| 选项 | 行为说明 |
| --- | --- |
| **日间模式** | 切换为纯净浅色单色调画布与浅色毛玻璃悬浮控件，适合白天阅读、演示与截图导出。 |
| **夜间模式** | 切换为低眩光深色画布与深色毛玻璃控件，语义 Tag 自动调整为暗底柔亮对比度。 |

主题偏好会自动持久化在浏览器本地存储中，刷新或重新打开工作区后保持一致；同时 `clado.brand` 作为常驻插件管理入口不可在面板内关闭，防止误关闭后无法重新启用其他插件。

### 2. 截取当前画布

点击 **截取当前画布** 后，设置菜单自动收起，Clado 会将当前视口下的画布画面（包含卡片排版、曲线连线与语义 Tag）一键导出为高清 PNG 图像，便于快速粘贴到需求评审群、周报或 PR 描述中。

### 3. 可视化插件管理与配置

点击 **插件管理** 弹出居中毛玻璃模态框，无需手写 JSON 即可管理全部内置与外部插件：

- **运行状态与开关**：列表展示每个插件的图标、名称、版本或状态说明，右侧提供开关切换启用 / 停用；变更后底部提示「应用并刷新」，点击即保存配置并重新挂载画布。
- **可视化插件配置**：点击插件行的 **设置** 按钮，可按表单字段直接编辑插件配置（例如编辑 `clado.agent` 的 LLM 接口协议、Base URL、API Key、默认模型与思考模式）。
- **一键安装本地插件**：点击弹窗右上角 **安装插件**，选择包含 `clado-plugin.json` 的本地插件文件夹；系统会先校验清单结构、文件体积上限（单清单 ≤ 64KB、总计 ≤ 8MB）并**明文列出插件请求的权限清单**，经你二次点击「确认安装」后才会写入当前工作区的 `.clado/plugins/` 目录。

## 常见使用场景

- **汇报 / 评审导出**：切到「日间模式」调整好聚焦调用链，点一次 **截取当前画布** 直接保存高清图。
- **配置原生垂直 Agent**：打开 **插件管理** → 找到 **灵感**（`clado.agent`）→ 点击 **设置**，填入你的 OpenAI 兼容或 Anthropic API 凭据即可启用真 Token 流式推理。
- **极简演示模式**：在 **插件管理** 中临时关闭不需要的辅助插件，只留下纯净全屏画布做方案宣讲。
