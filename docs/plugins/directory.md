# `clado.directory` · 文档目录与工作区

`clado.directory` 是画布左下角的**文档导航抽屉与多工作区切换器**，让你在不离开画布的前提下快速浏览目录树、按关键词过滤文档、切换多个子工作区，并随时回看 Markdown 纯文本源文。

## 位置与外观

- **桌面端位置**：固定悬浮于画布左下角（`bottom-left` 插槽）。
- **收起状态**：呈现为紧凑毛玻璃胶囊按钮，展示文件夹图标、`文档` 标签与当前工作区有效文档总数（例如 `文档 4`）；多工作区模式下会同时显示当前工作区名称，帮助快速确认所处上下文。
- **展开状态**：向上平滑展开透明毛玻璃抽屉面板（`#directory`），内部自上而下分为 **工作区切换区**（多工作区时自动出现）、**即时搜索框**、**树状文档目录**、**本地同步状态条**与**底部快捷操作栏**。
- **移动端适配**：小屏设备上点击左下角触发按钮后，抽屉自动变形为**居中底部弹窗（Bottom Sheet）**，配有大触控搜索框与防误触行高，滑动目录列表丝滑不与画布手势冲突。

## 核心功能详解

### 1. 多子工作区即时切换

当你使用 `clado serve <父目录>` 同时托管多个项目时，抽屉顶部会自动出现 **工作区** 区域：

- 清晰列出所有已注册的子工作区，当前激活项高亮标识；
- 点击即可无缝切换当前画布对应的工作区，文档树、实时监听与 MCP 上下文同步切换，无需重启服务。

### 2. 树状目录与即时检索

- **层级文件夹折叠**：自动按 `.clado/doc/` 下的真实子目录结构渲染可折叠树，记录你的手动展开/收起状态；每个文件项主标题显示文档一级标题（`#`），副标题显示文件名。
- **即时名称与路径搜索**：在搜索框输入任意中英文关键词或路径片段，目录树实时过滤并自动展开匹配的子文件夹，清空输入后恢复原有折叠状态。

### 3. 历史返回、手动刷新与源文查看

抽屉底部固定三个高频操作按钮：

| 按钮 | 功能说明 |
| --- | --- |
| **`← 返回`** | 沿你的跨文档跳转历史回退上一份画布（例如通过跨文档链接跳到下游方案后一键返回上游）。 |
| **`刷新`** | 主动触发本地目录重新扫描并重载当前文档 AST 与渲染视图。 |
| **`源文`** | 在居中的毛玻璃弹窗（`<dialog>`）中只读查看当前画布对应的原始 `.md` 纯文本，直观验证“所见即纯文本”。 |

### 4. 实时同步状态与跳过文件提示

- **同步状态条**：持续反馈与本地目录 SSE 的连接状态（如 `已同步本地目录`、`检测到外部更新`）。
- **跳过文件提醒**：若目录中存在因语法异常或体积限制被跳过的文档，底部会浮现提示按钮，点击可在详情弹窗中查看跳过原因，避免文档“无声消失”。

## 对外暴露的 MCP 能力（`directory`）

`clado.directory` 通过插件宿主注册了标准 `directory` 能力：

- 当外部 AI 客户端调用 `clado_capabilities`（`action: "call"`，调用 `clado.directory` 的 `directory` 能力）请求切换当前浏览器展示的画布时，由该插件接管并平滑打开目标 `.md` 文档，实现「AI 说看哪份设计，你的浏览器自动翻到那一页」。
