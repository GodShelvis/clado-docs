# 实时现场感与人机拍板

当 AI 正在理解代码、修改画布或需要你做架构权衡时，Clado 通过 **SSE 实时事件流 + 克制的视觉体感反馈 + 原生 `ask_user` 决策卡**，让你始终清楚 AI 正在做什么、改了哪里、需要你决定什么。

## 1. SSE 实时推送与「跟随 AI 视角」

- 内核通过 `GET /library/events` 向每个子工作区推送结构化实时事件（`doc.updated` / `ai.activity` / `ai.focus` / `ai.waiting`），画布无需手动刷新。
- 灵感面板顶栏提供 **「跟随」开关**：开启后，当 AI 调用 `canvas_focus` 或读写某张卡片时，画布镜头会以 `280ms` 平滑平移至目标位置；关闭后你可以自由浏览其他卡片，互不打扰。
- 每轮对话结束后，面板自动汇总 **「本轮画布变更清单」**，点击任意一项立即平滑跳转定位到对应卡片。

## 2. 克制的 AI 活跃反馈（≥80% 底边羽化柔光）

为了不让界面显得花哨，Clado 严格区分「静止阅读态」与「AI 处理中」：

- **静止卡片 / 普通点击悬停**：保持纯粹的中性单色细边框，**没有任何彩色边框或发光**。
- **AI 正在读取 / 修改卡片或面板生成中**：在目标卡片或灵感面板的**底边中央泛起延伸至 ≥80% 宽度的羽化呼吸柔光**（移动端底部抽屉自动移至抽屉顶边中央），在体感上温和反馈「正在处理，请稍候」。
- **等待人工拍板（`ask_user`）**：画布关联卡片切换为柔和琥珀色底边呼吸光晕，底部浮出轻盈的毛玻璃状态提示条。

## 3. 原生 `ask_user` 决策提问卡

遇到需求歧义、数据一致性权衡或破坏性变更时，内置 Agent 不会替你擅自猜测，而是调用 `ask_user` 暂停当前推理循环：

1. 对话面板渲染结构化决策卡片，展示清晰问题 + 2–4 个一键点选方案 + 自定义补充输入框；
2. 画布同步高亮关联卡片并提示「等待你的确认」；
3. 你点选方案或输入补充决策后，会话**无损原地续跑**（即使刷新页面，挂起状态也会从 `.clado/sessions/` 完整恢复）。
