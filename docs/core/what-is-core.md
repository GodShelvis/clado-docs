# Clado 本体（核心引擎）

很多人第一次接触 Clado 时会看到四角的毛玻璃悬浮控件——左上角的品牌菜单、右上角的视图切换、左下角的文档目录和右下角的灵感 Agent。**这些界面外壳其实都是内置插件**。

把所有插件全部关闭后，剩下依然完整运转的部分，就是 **Clado 本体（Clado Core）**。理解本体与插件的边界，有助于你理解为什么 Clado 既轻盈又具备强扩展性。

![Clado 本体内核与四大内置插件插槽分布](/images/plugin-slots-map.svg)

---

## 一句话定义 Clado 本体

> **Clado 本体 = 纯文本 Markdown 图谱解析器 + 多工作区原子存储引擎 + 无边框无限画布运行时 + Streamable HTTP MCP 协议网关 + 插件沙箱宿主。**

即便一个内置 UI 插件都不挂载，Clado 本体依然是一个完整的本地引擎：浏览器直接呈现全屏无边框交互画布，本地目录的 `.md` 文件实时解析并双向同步，任何外部 MCP 客户端依然可以通过 `/mcp` 端点自由读写文档与节点。

---

## 本体自带的五大不可变支柱

### 1. Markdown 与语义 Tag 图谱引擎

本体内置无依赖的文档解析与校验内核，负责将一份标准 `.md` 纯文本映射为结构化节点图：

- **节点树构建**：识别一级标题（`#`）作为独立卡片节点，二级至六级标题（`##`–`######`）作为卡片内部层级小节（在脑图视图中自然展开为子树）。
- **语义 Tag 与二元连线解析**：解析正文、列表、表格、代码行与 Mermaid 节点中的语义 Tag 锚点（`{#id .color}`），并将标准 Markdown 链接 `[文案](目标卡片)` 与 `[文案](#tagId)` 解析为有向图边。
- **实时诊断校验**：自动检测空标题、重复 `tagId`、悬空链接目标与模板违规，生成结构化诊断列表供视图层与 MCP 工具消费。
- **静态构建与导出**：支持脱离服务运行，直接将 `.md` 目录编译为独立静态 HTML 产物（`clado build`）。

### 2. 多工作区与原子写盘存储层

本体直接以本地文件系统为唯一事实源，不引入私有数据库或二进制缓存：

- **单目录 & 多子工作区托管**：既可以启动单个项目目录，也可以托管包含多个子项目的父目录，每个工作区拥有独立的 `.clado/doc/`、模板、插件与会话目录，彼此严格隔离。
- **路径逃逸拦截与写锁**：所有文件读写强制限制在目标工作区根目录内，采用临时文件原子替换（Atomic Write）与并发写锁，防止多 AI 客户端同时修改导致文件损坏。
- **引用级联重写**：重命名文档或卡片标题时，本体自动更新跨文档链接，并保留 `#tagId` 锚点后缀。

### 3. 全屏无限画布与三视图渲染运行时

浏览器打开画布时，满屏承载内容的区域完全由 Clado 本体驱动：

- **三大视图引擎**：内置**卡片视图**（自动分层布局 + 贝塞尔连线）、**脑图视图**（左右发散思维导图与节点折叠）和**文档视图**（顺滑长文排版）三套渲染器，由同一份 AST 实时驱动。
- **镜头与触控交互**：内置画布平移、滚轮缩放、单指拖拽、双指捏合缩放、视口自适应居中与 URL 状态同步。
- **点选聚焦与调用链追踪**：点击卡片或语义 Tag 锚点，本体自动高亮上下游连线、淡化无关背景，并在卡片与连线之间保持精准坐标重算。
- **SSE 实时现场总线**：通过 Server-Sent Events 将文件变更、AI 读写节点状态与聚焦指令毫秒级推送到浏览器；当 AI 正在处理节点时，本体负责驱动该卡片底边中央的柔和羽化光条与实时定位脉冲。

### 4. Streamable HTTP MCP 协议网关

本体在本地 HTTP 端口直接暴露符合 MCP 标准的 `/mcp` 端点，让任意 AI 客户端（Claude Code、Cursor、ZCode 等）具备画布级操作能力：

- **8 个核心工具**：涵盖空间与选区（`clado_workspace`）、模板管理（`clado_templates`）、文档生命周期（`clado_documents`）、节点细粒度增删改（`clado_nodes`）、精准连线（`clado_links`）、事务批处理（`clado_batch`）、插件能力动态路由（`clado_capabilities`）以及实机截图（`clado_screenshot`）。
- **人机共享上下文**：你在浏览器中多选的卡片、点击的语义 Tag 与当前聚焦视图，本体都会通过 `clado_workspace(action: "selection")` 实时同步给 MCP 会话。

### 5. 插件宿主与安全沙箱

Clado 本体本身**不硬编码**菜单栏、侧边栏或对话窗口，而是通过标准宿主接口向外开放扩展能力：

- **四角悬浮插槽（Slots）**：提供 `top-left`、`top-right`、`bottom-left`、`bottom-right` 四个桌面端悬浮锚点，并在移动端自动协调底部抽屉（Bottom Sheet）与安全区避让。
- **统一毛玻璃设计令牌**：向插件提供 `.clado-ui-glass`、`.clado-ui-glass-panel`、`.clado-ui-button`、`.clado-ui-dialog` 等浅/深双主题一致的视觉原语。
- **命名空间保护与沙箱隔离**：`clado.*` 命名空间由内核强保护，第三方插件无法冒充或劫持；外部 UI 插件运行于受控 `iframe` 沙箱，权限须经分级审计。

## 本体、内置插件与外部插件的边界

| 层级 | 职责边界 | 是否可禁用 / 替换 | 典型代表 |
| --- | --- | --- | --- |
| **Clado 本体（Core）** | 解析渲染、三视图画布、存储、MCP 网关、SSE 总线、插件宿主 | **不可关闭**（系统底座） | 画布渲染器、`/mcp` 服务、CLI 引擎 |
| **内置插件（`clado.*`）** | 覆盖高频人机交互外壳，随产品默认分发并受命名空间保护 | **支持在插件管理中按需开关** | [`clado.brand`](/plugins/brand)、[`clado.view-controls`](/plugins/view-controls)、[`clado.directory`](/plugins/directory)、[`clado.agent`](/plugins/agent) |
| **外部插件（Community / Custom）** | 扩展团队自定义 UI 能力、数据源桥接或自定义 ACP 执行器 | **自由安装、启用与卸载** | 内部工单卡片插件、内网穿透插件、自定义代码执行器 |

::: tip 设计哲学：内核极简，外壳可插拔
将设置菜单、目录抽屉、视图切换和 AI 灵感面板全部拆为内置插件，意味着：
1. 你在**嵌入静态预览或极简演示**时，可以按需关闭多余控件，只留下纯净画布；
2. 内置插件与外部插件共享同一套插槽与毛玻璃视觉体系，第三方开发者也能做出和官方质感完全一致的体验。
:::
