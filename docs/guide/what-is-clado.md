# 什么是 Clado？

**Clado**（npm 包名 `cladogram`）是一个面向 **AI 时代软件研发协作** 的 Markdown 可视化画布、Streamable HTTP MCP 服务端与独立垂直 Agent 平台。

## 核心理念：AI 是操作手，人是观察者与指挥官

传统白板或架构图工具默认由人手工拖拽、对齐、拉线，一旦代码迭代，文档与真实实现就会迅速脱节。Clado 将协作重心倒置：

1. **人负责观察、审查与拍板**：你在浏览器画布里按需逐层展开阅读——用 **卡片视图** 追踪接口到代码的调用链路，用 **脑图视图** 评审需求范围与测试用例树，用 **文档视图** 按文章顺序精读；按住 `Cmd / Ctrl` 点选几张卡片，直接告诉 AI 要改什么。
2. **AI 负责理解代码与维护画布**：无论是内置垂直 Agent，还是外部接入的 ZCode / Claude Code / Cursor / Codex，都通过 **Streamable HTTP MCP** 读取你的选区、核对模板约束、执行原子化增删改连。
3. **纯文本是唯一事实源（Single Source of Truth）**：每一张卡片、每一个层级、每一条连线与语义 Tag 锚点，都明文保存在标准 `.md`（永久兼容 `.mdc`）文件中，直接放进 Git、VS Code 或 GitHub 依然干净可读，没有任何私有二进制格式。

## 典型研发工作流

| 阶段 | 推荐视图 | Clado 如何协助 |
| --- | --- | --- |
| **1. 存量代码摸底** | 卡片视图 | 内置本地只读代码探针（目录树、符号检索、精准行读、Git Diff），先核对真实类与方法边界，拒绝 AI 编造。 |
| **2. 需求与架构设计** | 卡片视图（默认） | 按官方模板生成调用链、数据设计、业务流画布；用 6 色语义 Tag 标明新增/修改/删除，并以 `#tagId` 精准连线到代码行。 |
| **3. 测试用例评审** | 脑图视图 | 使用 `test-cases` 模板按「正常流 / 边界条件 / 异常流」展开脑图用例树，支持多选卡片定向补充。 |
| **4. 派发代码开发** | 灵感面板（ACP） | 在画布面板内一键把拍板的设计规格 `.md` 派发给外部 Coding Agent（ZCode / Claude Code / Codex），全程免切窗口。 |
| **5. Diff 验收与归档** | 卡片 + 文档视图 | 开发完成后自动比对本地 Git Diff 与画布契约，更新系统现状归档，或一键 `clado build` 导出单文件离线 HTML 交付。 |
