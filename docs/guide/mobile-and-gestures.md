# 移动端适配与触控手势

Clado 在完整保留桌面端所有工作台功能的前提下，针对手机与平板屏幕（`≤ 680px`）提供了原生级响应布局与多点触控手势支持，方便配合内网穿透随时随地在手机上查看架构图、审阅文档并指挥 AI。

## 响应式布局对照

| 区域 | 桌面端（`> 680px`） | 移动端（`≤ 680px`，适配安全区） |
| --- | --- | --- |
| **左上角品牌** | `C` 标 + `clado` 文字胶囊 | 自动收拢为紧凑 `42×42px` `C` 标按钮，把顶部空间留给视图切换 |
| **右上角视图切换** | `卡片 \| 脑图 \| 文档` 毛玻璃分段器 | 完整保留三视图切换，`36px+` 舒适触控高度 |
| **左下角文档目录** | 悬浮弹出目录面板 | 底栏胶囊自动截断文件名防止与「灵感」按钮重叠；展开时转为全宽 **Bottom Sheet 底部抽屉** |
| **右下角灵感 Agent** | 右下角悬浮玻璃对话窗（AI 运行时底边 ≥80% 羽化柔光） | 展开时自动切换为全宽 **Bottom Sheet 底部抽屉**（带顶部拖拽把手、`44px` 拇指热区、`16px` 防 iOS 自动缩放输入框），AI 运行柔光自动移至抽屉**顶边中央** |
| **文档视图** | 左侧固定大纲 + 右侧正文双栏 | 自动切换为单栏全宽精读排版 |

## 移动端原生触控手势

- **单指拖拽空白画布**：平滑平移画布视口，不误触发页面默认滚动或文本选中。
- **双指捏合缩放（Pinch-to-Zoom）**：在画布任意位置（包括卡片上方）双指开合，以两指中点为锚点平滑缩放（`0.2x` – `2.5x`），同步重绘卡片与脑图连线。
- **卡片正文纵向滑动**：当卡片被收矮出现内部滚动条时，卡片内保留 `touch-action: pan-y` 自然纵向滑动。
- **单击代码 / 表格 / Mermaid**：进入无边框毛玻璃放大镜（Lens），同样支持触控平移与缩放。

::: tip 安全区兼容（Notch / Home Indicator）
页面内置 `viewport-fit=cover` 与 `env(safe-area-inset-*)` 边距计算，在 iPhone / Android 全面屏浏览器与 PWA 全屏模式下，四角悬浮控件与底部抽屉输入框均不会被刘海或底部手势条遮挡。
:::
