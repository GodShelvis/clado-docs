# 三大视图与画布交互

Clado 不会把你的文档锁死在单一展示形态里。右上角内置受保护的三视图切换器，默认顺序为：**卡片视图（默认）→ 脑图视图 → 文档视图**。三视图共用同一份 Markdown 源文与多选选区，切换毫秒级完成。

## 1. 卡片视图（默认 · `clado.view.cards`）

最适合**调用链路、系统架构、接口契约与数据流转**。

- 每个一级标题 `#` 渲染为一张独立卡片，按链接关系自动自左向右拓扑分列。
- **对齐基准**：以卡片左上角蓝色竖条为对齐中心，父卡蓝条自动垂直居中对齐到其可见子卡蓝条的中点。
- **按需展开 / 收起**：点击卡片右侧端口展开或收起下游分支——展开时**仅移动当前分支，其余卡片与镜头保持不动**，绝不让你迷路。

![卡片视图实机截图](/images/hero-cards-light.png)

## 2. 脑图视图（`clado.view.mindmap`）

最适合**需求范围拆解、思维发散与测试用例树**。

- 将文档内的 `L1–L6` 标题层级直接展开为从左至右的树状分支；
- 文中跨卡链接渲染为辅助虚线，既保留结构包含关系，又不丢失跨模块依赖。

![脑图视图实机截图](/images/view-mindmap.png)

## 3. 文档视图（`clado.view.doc`）

最适合**长文顺读、完整表格/代码核对与大纲快速跳转**。

- 桌面端提供左侧固定大纲 + 右侧正文双栏阅读；移动端自动切换为单栏全宽排版。
- 保留全部语义 Tag、代码块高亮、Mermaid 流程图与跨文档链接跳转。

![文档视图实机截图](/images/view-doc.png)

## 聚焦、提取链路与无边框放大镜（Lens）

- **双击标题（聚焦模式）**：高亮当前节点与全部上下游关联链路，自动隐藏无关卡片。
- **长按标题（提取独立链路）**：在独立浮层画布中只展示该节点的关联上下游，主画布与子画布各自保存取景。
- **单击代码块 / Mermaid 图 / 表格（放大镜 Lens）**：弹出无边框透明毛玻璃放大层，四角 HUD 平滑淡出，支持滚轮缩放、拖拽与文本复制，按 `Esc` 立即退出。

![聚焦模式与链路高亮](/images/focus-chain.png)

## 快捷键与手势速查

| 操作 | 效果 |
| --- | --- |
| **Mac `Cmd + 左键` / Win·Linux `Ctrl + 左键`** 点击标题 | 多选卡片或小节（三视图同步选区，并实时同步给 MCP `selection`） |
| 按住 `Cmd / Ctrl` 点画布空白 | 清空当前多选选区 |
| **双击**标题 | 进入 / 退出聚焦模式 |
| **长按**标题 | 提取关联链路到独立浮层画布 |
| **单击**代码块 / 表格 / Mermaid | 打开无边框毛玻璃放大视图（Lens） |
| 拖拽画布空白 / 滚轮 / 双指捏合 | 平移与缩放画布；按 `0` 键一键适配全图 |
| 拖拽卡片右下角 | 调节卡片可视高度（收矮后内部出现细滚动条，端口自动贴边不溢出） |
